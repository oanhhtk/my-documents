# Introduction

Đây là **bộ tài liệu kỹ thuật** (knowledge base) tổng hợp ghi chép, hướng dẫn và cheat sheet cho phát triển ứng dụng web — trọng tâm là **Nuxt** và các chủ đề liên quan (SSR, Nitro, DevOps). Site được tạo bằng **[Nextra](https://nextra.site)** trên **Next.js**, dùng theme **nextra-theme-docs** để có sidebar, search và bố cục tài liệu nhất quán.

Bạn có thể **điều hướng theo menu bên trái**; các mục chính khớp với cấu trúc thư mục trong `pages/`.

## Cấu trúc thư mục (tóm tắt)

```text
pages/
├── mastering-nuxt/      # Khóa học / hướng dẫn Nuxt
├── nuxt-architecture/   # SSR, Nitro, H3, request flow
├── case-studies/        # Case studies / kinh nghiệm tích lũy
├── gitlab-cicd/         # CI/CD
├── advanced/            # Thử nghiệm
└── index.mdx            # Trang này
```

Mỗi thư mục con có **`_meta.ts`** điều khiển **nhãn hiển thị** trong sidebar của Nextra.

## Mục đích sử dụng

- **Tra cứu nhanh** khi làm việc với Nuxt (lifecycle, storage, backend stack).
- **Chia sẻ trong team** hoặc dùng làm **personal wiki**.
- **Mở rộng** bằng cách thêm file `.mdx` mới và cập nhật `_meta.ts` tương ứng.

Nếu bạn vừa vào đây lần đầu, nên bắt đầu từ **[Mastering Nuxt](/mastering-nuxt/setup-ideal-extensions)** hoặc **[Nuxt Architecture → SSR lifecycle](/nuxt-architecture/nuxt-ssr-lifecycle)** tùy nhu cầu.
